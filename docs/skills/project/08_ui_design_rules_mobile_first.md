# 08 UI Design Rules (Mobile First)

References:

- `../../core/04_design_system_mobile_first.md`
- `../../core/07_frontend_routes_and_flows.md`

## Rules

- Mobile-first always.
- Reuse tokenized spacing/colors/typography.
- Keep behavior consistent across marketing/platform/admin surfaces.

## Do

- Validate responsive behavior per mode.
- Keep component contracts predictable.

## Don't

- Introduce visual regressions between modes.
- Break design token usage.
