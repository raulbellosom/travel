# 07 i18n and Content Rules

References:

- `../../core/00_ai_project_context.md`
- `../../core/04_design_system_mobile_first.md`

## Language policy

- Spanish UTF-8 is primary.
- Multilingual support remains active.

## Do

- Keep user-facing copy Spanish-first where not localized yet.
- Preserve UTF-8 integrity.
- Use stable i18n key naming.

## Don't

- Ship broken accents or bad encoding.
- Hardcode English as default business copy.
